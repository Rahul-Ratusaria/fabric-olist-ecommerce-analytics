# Enterprise E-Commerce Analytics Platform

## Business Problem

The organization stores data across multiple CSV files containing customer information, orders, products, sellers, payments, reviews, and geolocation. Business users currently have no centralized platform to analyze operational performance, customer behaviour, delivery efficiency, or sales trends.

The objective of this project is to build an end-to-end analytics platform using Microsoft Fabric that ingests raw data into OneLake, transforms it using a Medallion Architecture (Bronze, Silver, Gold), models it into an analytical star schema, and exposes interactive dashboards through Power BI.

## Business Goals

- Analyze overall sales performance
- Monitor customer purchasing behavior
- Evaluate seller performance
- Identify top-performing products
- Monitor delivery efficiency
- Analyze customer reviews
- Build reusable data pipelines
- Demonstrate enterprise data engineering practices

## Success Criteria

- Automated data ingestion
- Data quality validation
- Bronze -> Silver -> Gold architecture
- Star Schema
- Power BI dashboard
- Github documentation
