# Project Demonstration

This folder will contain the script and supporting material for the final project demonstration.

---

## Planned Demo

The final demonstration will be approximately two to four minutes long.

It will cover:

1. business problem;
2. architecture;
3. Kaggle-to-OneLake ingestion;
4. Bronze, Silver and Gold layers;
5. data-quality framework;
6. Fabric pipeline;
7. semantic model;
8. Power BI dashboard;
9. key business insights;
10. GitHub repository.

---

## Planned Files

| File | Purpose |
|---|---|
| `demo_script.md` | Spoken walkthrough script |
| `demo_checklist.md` | Recording preparation checklist |
| `demo_link.md` | Link to the published recording |

---

## Demo Rules

The recording must not display:

- access tokens;
- personal credentials;
- private email content;
- tenant-sensitive details;
- Kaggle credential files;
- signed URLs.

The demo should focus on business value and architectural decisions rather than only showing interface clicks.

---

## Suggested Demo Structure

### Opening

Explain the business problem and project objective.

### Architecture

Show the end-to-end Fabric data flow.

### Data Engineering

Show ingestion, Lakehouse tables and quality validation.

### Analytics

Show the semantic model and dashboard pages.

### Closing

Summarize skills demonstrated and direct the viewer to the GitHub documentation.
