# Enterprise E-commerce Analytics Dashboard

End-to-end Microsoft Fabric Lakehouse and Power BI analytics project using the Olist Brazilian E-Commerce dataset.

## Technologies

- Microsoft Fabric
- Onelake
- Lakehouse
- Data Warehouse
- PySpark
- SQL
- Power BI
- Data Factory

## Dataset

[Olist Brazalian E-commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce?utm_source=chatgpt.com)
